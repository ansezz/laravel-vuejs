# Security policy

laravel-vuejs.space is a static Astro site with a small Cloudflare Worker for forms.

## Reporting a vulnerability

Please report security issues privately, not in public issues:

- GitHub: [open a private security advisory](https://github.com/ansezz/laravel-vuejs/security/advisories/new), or
- Email: contact@laravel-vuejs.space (subject "Security").

Include the URL, steps to reproduce and the impact. We aim to acknowledge reports within 5 working days and will credit you if you want. Please don't access other people's data, degrade the service or run automated scans that send large volumes of form submissions.

## Scope

- In scope: laravel-vuejs.space, www.laravel-vuejs.space, the form API (`/api/forms/*`) and this repository.
- Out of scope: third-party services we link to or embed (Disqus, social networks), and missing best-practice headers without a demonstrable impact.
