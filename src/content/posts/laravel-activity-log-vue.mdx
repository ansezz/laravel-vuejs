People searching "Laravel activity log Vue" install a package and then log `$request->all()`. That stores the password. Log a sentence and the subject. The [policy guide](/laravel-vue-policies) is who may open the page that lists those rows.

<TLDR audience="Laravel + Vue developers" applies="Laravel 13 · Vue 3">

- Log the subject and the user from the controller.
- Pass the latest rows as a prop.
- Do not log a password.
- Do not put the `properties` JSON on a page any user can open until you have read what you stored.

</TLDR>

## The fix

Spatie's package is the one this search usually means:

```shell
composer require spatie/laravel-activitylog
php artisan vendor:publish --provider="Spatie\Activitylog\ActivitylogServiceProvider" --tag="activitylog-migrations"
php artisan migrate
```

```php
activity()
    ->performedOn($post)
    ->causedBy($request->user())
    ->log('updated the post');
```

Pass the latest rows to an admin page only:

```php
'activity' => Activity::query()->latest('id')->limit(20)->get(['id', 'description', 'created_at']),
```

## What to avoid

<Callout type="gotcha">

Do not put the `properties` JSON on a page any user can open until you have read what you stored. Do not log attribute changes on `User` without an except list. Tokens and passwords do not belong in `activity_log`.


</Callout>
