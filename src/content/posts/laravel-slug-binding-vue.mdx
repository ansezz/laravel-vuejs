People searching "Laravel slug route Vue" put the title in the URL and then a renamed post 404s every old link. Store a slug and bind that column.

<TLDR audience="Laravel + Vue developers" applies="Laravel 13 · Vue 3">

- getRouteKeyName can return slug.
- The column has to be unique.
- The title is not a key.
- Do not use the title as `getRouteKeyName()`.

</TLDR>

## The fix

```php
public function getRouteKeyName(): string
{
    return 'slug';
}
```

```php
Route::get('/posts/{post}', [PostController::class, 'show'])->name('posts.show');
```

`/posts/hello-world` resolves `where slug = hello-world`. The Vue page still receives the post prop. Generate the slug once when the post is created, from the title, and keep it stable when the title changes. A unique index on `slug` is what makes the binding mean one row.

Validate the slug with a rule that allows lowercase letters, numbers, and hyphens, plus `Rule::unique('posts', 'slug')->ignore($post->id)` on update.

## What to avoid

<Callout type="gotcha">

Do not use the title as `getRouteKeyName()`. Spaces and renamed titles break the [Wayfinder](/laravel-wayfinder-vue) URL you already sent to the browser. Do not look the slug up in Vue from a list of every post.


</Callout>
