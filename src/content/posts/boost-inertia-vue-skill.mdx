People searching "inertia-vue-development" look for an npm package. It is a guideline Laravel Boost writes for the coding agent. The [Boost guide](/laravel-boost-vue) explains the install. Inertia 1, 2, and 3 each have a skill. Boost picks the one that matches the installed major.

<TLDR audience="Laravel + Vue developers on Inertia" applies="Laravel 13 · Inertia 3 · Vue 3">

- Boost's inertia-vue-development skill matches the Inertia major you installed.
- It is not a Vue component.
- Do not copy the skill into a Vue page.
- Do not install a second copy of the guidelines by hand and then run `boost:update`, which overwrites them.

</TLDR>

## The fix

```shell
composer require laravel/boost --dev
php artisan boost:install
```

After an upgrade, `php artisan boost:update` rewrites that skill so the agent stops suggesting Inertia 2 APIs in an Inertia 3 app. The human-readable page for the stack is still the [2026 guide](/laravel-vue-in-2026).

## What to avoid

<Callout type="gotcha">

Do not copy the skill into a Vue page. Do not install a second copy of the guidelines by hand and then run `boost:update`, which overwrites them. If the agent suggests Vue Router on the starter kit, the skill is stale or the agent is not reading it. Update Boost before you follow the suggestion.


</Callout>
