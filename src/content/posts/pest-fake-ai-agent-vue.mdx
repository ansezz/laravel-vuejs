People searching "Pest fake AI agent" hit the real model from a feature test. Fake the agent. The [tests guide](/test-laravel-vue) is the rest of the feature test. The [AI SDK guide](/laravel-ai-sdk-vue) is the controller this test hits.

<TLDR audience="Laravel + Vue developers" applies="Laravel 13 · Vue 3">

- DraftReply::fake() returns a canned string.
- assertPrompted checks the note.
- The test does not call the provider.
- Do not assert on the provider's JSON.

</TLDR>

## The fix

```php
use App\Ai\Agents\DraftReply;
use App\Models\User;

it('drafts a reply', function () {
    DraftReply::fake(['Rewritten.']);

    $user = User::factory()->create();

    $this->actingAs($user)
        ->post('/replies', ['note' => 'Ship the form.'])
        ->assertRedirect()
        ->assertSessionHas('draft', 'Rewritten.');

    DraftReply::assertPrompted('Ship the form.');
});
```

`fake` prevents the HTTP call. `assertPrompted` fails when the controller sent `$request->all()` or an empty string. `preventStrayPrompts()` fails the test when some other agent ran.

## What to avoid

<Callout type="gotcha">

Do not assert on the provider's JSON. You faked past it. Do not leave a real key in `.env.testing` and skip the fake "just for one test". That test will cost money and flap.


</Callout>
