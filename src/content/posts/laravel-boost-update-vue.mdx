People searching "Laravel Boost update" run `npm update` and expect the Vue guidelines to change. Boost is a Composer dev dependency. The [Boost guide](/laravel-boost-vue) is the install. This page is the command after you bump Inertia or Laravel.

<TLDR audience="Laravel + Vue developers" applies="Laravel 13 · Vue 3">

- boost:update rewrites the agent guidelines for the versions you installed.
- Boost is not an npm package.
- Do not hand-edit a paragraph you need to keep inside a file the next update overwrites.
- Do not put a provider API key in `boost.json`.

</TLDR>

## The fix

```shell
composer require laravel/boost --dev
php artisan boost:update
```

`boost:install` is the first time. `boost:update` refreshes the guideline files and the MCP config for the packages now in `composer.json`. Restart the coding agent after it runs so the agent reads the new files.

The docs say those generated files can be gitignored, because the commands rewrite them. Do not hand-edit a paragraph you need to keep inside a file the next update overwrites. Put a project rule in your own file.

## What to avoid

<Callout type="gotcha">

Do not put a provider API key in `boost.json`. Do not add Vue Router or Ziggy because an old guideline mentioned them. The [stack guide](/laravel-vue-in-2026) is the current choice.


</Callout>
